# Clard 需求清单（用户操作层）

> 基线：clash-verge-rev dev 分支（本地核对 2026-09-13），功能面来源：
> 前端页面 `src/pages/*`、Tauri 命令 `src-tauri/src/cmd/*`、设置结构 `config/verge.rs`（`IVerge`）。
> 范围：**仅用户操作层**（页面/操作/设置项）；内部机制（watchdog/审计/IPC/TUN 落地）不入此表。
>
> 标记：✅ clard 已定义 · ⬜ 缺口（需补详细设计）· ➖ clard 明确排除 · ❓ 待定
>
> clard 自有（非 clash-verge 提取，已定义）：审计日志、TUN 旁路、fail-open 紧急恢复直连、系统级不分用户。

## 10. 需求缺口汇总（clard 待补详细设计）

**高优先（用户日常操作）**
1. **规则页**（§6）：规则列表/搜索/启用禁用——是否独立页、入口放哪，需决策。
2. **订阅信息展示**（§2）：流量/到期（`subscription-userinfo` 响应头解析）。
3. **配置改名 / 排序**（§2）：独立 rename 操作；列表排序规则。
4. **切换事务的 selected 记忆**（§2/§3）：`ProfileItem.selected` 落库与恢复时机。
5. **节点测速 URL 配置**（§3）。

**中优先**
6. **merge/规则/节点 追加项**（§2）：订阅外附加内容如何进 config_gen（对齐 clash-verge `PrfOption`）。
7. **连接页搜索 + 连接详情**（§4）。
8. **备份/恢复**（§7.6）：`/var/lib/clard` 打包导出/导入。
9. **本地配置（local）**（§2）：粘贴 yaml 或空配置。
10. **媒体解锁检测**（§9）。

**低优先/决策项**
11. 开机自启开关、内存显示、DNS 配置编辑器、Chain、语言、启动页。
