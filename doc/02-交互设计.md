# Clard 完整代理管理工具 — 交互设计

> 版本：v0.1（设计稿） · 目标平台：Linux · 界面：TUI · 状态：待评审
> 与 `01-方案设计.md` 配套，键位与页面结构对应 `03-ui设计.md`。

## 1. 设计原则

1. **键盘优先，鼠标为辅**：所有高频操作必须有单键/组合键直达，鼠标点击为可选增强。
2. **即时反馈**：任何命令（切换、更新、测试）立即给出「进行中 → 成功/失败」反馈，不静默。
3. **不丢状态**：切换页面不重置列表滚动位置与选中项；错误只提示不阻塞。
4. **危险操作需确认**：删除配置、关闭全部连接、卸载服务等破坏性动作二次确认。
5. **可发现性**：页脚常驻快捷键提示；`?` 打开全局帮助。

## 2. 全局导航模型

### 2.1 页面（状态机）

```
┌─────────┐  1  ┌───────────┐  2  ┌──────────┐  3  ┌─────────────┐
│ 主页     │────▶│ 配置文件   │────▶│ 代理      │────▶│ 连接         │
│ Home    │     │ Profiles  │     │ Proxies  │     │ Connections │
└─────────┘     └───────────┘     └──────────┘     └─────────────┘
     ▲                                                      │
     │       5  ┌──────────┐  4  ┌──────────┐               │
     └──────────│ 设置      │◀────│ 日志      │◀──────────────┘
                │ Settings  │     │ Logs      │
                └──────────┘     └──────────┘
```

- 页面用 `1..6` 数字直达，`Tab` 进入内容区、`Esc` 返回/退出（见各页）。
- 页面间切换**保留**各自内部状态（选中行、滚动、过滤条件）。

### 2.2 全局键位（默认）

| 键 | 作用 | 备注 |
|---|---|---|
| `1`–`6` | 直达对应页面 | 主页/配置/代理/连接/日志/设置 |
| `↑` `↓` / `j` `k` | 列表上下移动 | 全页通用 |
| `←` `→` / `h` `l` | 左右面板切换 / 树展开收起 | 分栏页 |
| `Enter` | 确认 / 进入 / 触发主操作 | |
| `Tab` | 聚焦下一区域 / 切换页签 | |
| `Esc` | 返回上一层 / 关闭弹窗；主页时为退出 | |
| `q` | 退出（主页/弹窗外任意处） | 有未完成任务时确认 |
| `?` | 全局帮助浮层 | 任意页 |
| `Ctrl+c` | 强制退出（兜底） | 尽量走 `q` 以触发恢复 |

### 2.3 弹窗与确认

- **确认弹窗**：`Enter`=确认，`Esc`=取消，默认焦点在「取消」。
- **输入弹窗**（如订阅 URL、搜索）：单行输入，支持 `Ctrl+u` 清行、`Backspace` 删字符、`Enter` 提交、`Esc` 取消。
- **帮助浮层**：全屏半透明遮罩 + 键位表，`?`/`Esc` 关闭。

## 3. 页面交互

### 3.1 主页（Home / `1`）

**用途**：一屏总览，不承载复杂操作。

| 区域 | 展示 | 交互 |
|---|---|---|
| 核心状态 | Running/Starting/Stopped + 运行方式(Sidecar/Systemd) + PID | `s` 启动/重启，`S` 停止 |
| 当前配置 | 名称、类型、上次更新 | `Enter` 跳到 Profiles 页 |
| 代理开关 | 系统代理、TUN 各自 开/关 | `p` 切换系统代理，`t` 切换 TUN |
| 流量摘要 | 上/下行速率与总量 | 只读 |

### 3.2 配置文件（Profiles / `2`）

**用途**：配置文件全生命周期管理。

**列表视图**（默认焦点在列表）：

| 键 | 动作 | 反馈 |
|---|---|---|
| `↑↓/jk` | 移动选中 | 高亮行 |
| `Enter` | 切换为当前配置 | 状态行「切换中…」→「已切换/失败」 |
| `a` | 新增本地文件 | 文件选择弹窗 |
| `i` | 从 URL 导入 | 输入 URL（+可选名称/间隔） |
| `u` | 立即更新选中订阅 | 行内「更新中…」spinner |
| `e` | 编辑选项（间隔/UA/走代理） | 表单弹窗 |
| `d` | 删除 | 确认弹窗 |
| `r` | 重命名 | 输入弹窗 |
| `o` | 打开本地文件（`$EDITOR`） | 外部进程，返回后提示 |

**详情面板**（右侧，`l` 聚焦）：显示 uid、类型、URL、流量/到期、上次/下次更新、自动更新开关。

**规则**：`Enter` 切换时若核心未运行，自动先启动核心再切换；删除「当前」配置时自动选中下一个并切换。

### 3.3 代理（Proxies / `3`）

**用途**：查看分组树、选择节点、测延迟。

**树视图**（左右两栏）：

| 键 | 动作 |
|---|---|
| `↑↓/jk` | 上下移动 |
| `←→/hl` | 折叠/展开分组，或左右栏切换 |
| `Enter` | 选中分组内高亮节点（下发 `select_node_for_group`） |
| `t` | 对当前节点/分组测延迟 |
| `T` | 全部分组测延迟 |
| `d` | 清除该分组的固定选择（回退 URLTest 自动） |
| `s` | 按名称/延迟/类型排序 |
| `f` | 过滤（输入关键字） |

**反馈**：选中节点后分组 `now` 立即更新；延迟测试显示「…ms」或「超时」。

### 3.4 连接（Connections / `4`）

**用途**：查看活跃连接与实时流量。

| 键 | 动作 |
|---|---|
| `↑↓/jk` | 移动选中连接 |
| `u` / `d` | 按上行 / 下行排序 |
| `x` | 关闭选中连接 |
| `X` | 关闭全部连接（确认） |
| `c` | 切换「实时流量」显示单位（KB/s ⇄ 总量） |
| `r` | 手动刷新列表 |

**流量订阅**：进入本页自动订阅 `traffic` WebSocket，离开停止。

### 3.5 日志（Logs / `5`）

**用途**：应用 + 核心日志查看与诊断。

| 键 | 动作 |
|---|---|
| `Tab` | 切换 应用日志 / 核心日志 / 合并视图 |
| `↑↓/jk` | 滚动（跟随尾部时先解除跟随） |
| `e` | 级别过滤（循环 error→warn→info→debug） |
| `f` | 关键字过滤（输入） |
| `F` | 跟随/取消跟随尾部 |
| `c` | 清空当前视图 |
| `G` | 跳到末尾 |

### 3.6 设置（Settings / `6`）

**用途**：全局设置，分页签。

| 页签 | 配置项 | 交互 |
|---|---|---|
| 通用 | 开机自启、退出最小化、混合端口、局域网共享 | 选项式 `Enter` 切换 / 数字输入 |
| 系统代理 | 开关、后端（只读：KDE/GNOME/ENV/None）、旁路列表、守护间隔 | 同上；写入后读回校验，失败则消息条报错且开关回退为「关」 |
| TUN | 开关、dns-hijack、auto-route、服务安装状态 | 开关 + `i` 安装服务（触发 pkexec） |
| 核心 | 下载/升级核心、检查更新、运行方式 | 按钮式 `Enter` |
| 日志 | 级别、文件大小、保留数量 | 选项式 |
| 关于 | 版本、数据目录 | 只读 |

**规则**：设置改动即写盘（`clard.toml`）；涉及端口/TUN/DNS 的改动提示「需重启核心生效」，`Enter` 立即重启。

## 4. 状态与错误反馈

统一用三种通道反馈，避免信息丢失：

1. **页脚消息条**：最近一条结果（成功/失败 + 原因），5 秒后淡出，`m` 查看历史。
2. **行内状态**：列表项的实时状态（更新中 spinner、延迟值、错误标记）。
3. **日志页**：所有可诊断细节沉淀到日志，消息条只给结论。

错误分级：

| 级别 | 展示 | 例 |
|---|---|---|
| 提示 info | 页脚灰字 | 「配置已切换」 |
| 警告 warn | 页脚黄字 | 「订阅更新失败，保留旧文件」 |
| 错误 error | 页脚红字 + 日志 | 「核心启动失败：端口被占用」 |
| 致命 fatal | 弹窗 + 停止操作 | 「配置文件非法，无法生成运行时配置」 |

## 5. 典型任务流

### 5.1 首次使用（导入并启动）

```
启动 → 主页(核心 Stopped) → 2 进 Profiles → i 输入订阅 URL → Enter 导入
     → Enter 切换 → 自动启动核心 → 主页显示 Running + 当前配置
     → 6 设置 → 系统代理 开 → 完成
```

### 5.2 开启 TUN

```
6 设置 → TUN 页签 → 查看「服务未安装」→ i 安装(pkexec 授权)
     → 安装完成 → 开关 TUN 开 → 提示重启核心 → Enter → Running(Systemd, TUN on)
     → 主页确认 TUN 开
```

### 5.3 排查断网

```
5 日志 → Tab 切核心日志 → e 过滤 error → 定位报错
     → 主页 → S 停止核心 / p 关系统代理 → 恢复
```

## 6. 无障碍与可配置

- 键位集中定义在 `clard-tui` 的 keymap 模块，后续支持自定义键位文件。
- 颜色方案支持亮/暗，设置页切换（配 `03-ui设计.md`）。
- 所有交互文案中文，后续可抽离 i18n。
