# Clard 需求文档（用户操作层）

> 来源：clash-verge-rev 功能提取（见本文件早期版本的 git 历史）+ 决策修订。
> 范围：**仅用户操作层**；每个需求附「实现方法」（文字描述，不含代码）。
>
> **决策基线**（已确认）：
> - **不做**：local 配置、YAML 编辑器、脚本增强（script）、merge 全局覆盖、rules/proxies/groups 追加项、Chain、启动页、开机自启开关（helper 是 systemd 常驻服务，天然自启）。
> - **保留**：规则功能；语言默认**英语**、用 rust-i18n 转中文；**默认混合端口**；备份恢复。
> - 其余功能按 **TUI 可实现性**取舍：复杂或终端内不划算的去掉（见 §9 不做清单）。
>
> 数据链路总约定：TUI 无持久文件，一切经 IPC 交 helper（`/var/clard/lib`），审计记录每个操作者。

## 1. 页面与导航

**R1.1 七页导航**（主页 / 配置 / 代理 / 连接 / 日志 / 设置 / 规则；数字键 `1`–`7` 对应顺序，规则页为 `7`，见 doc/03 §2/§4.1/§5.5）
- 用户操作：数字键 `1`–`7` 直达；`Tab` 聚焦内容区；页面切换保留各页内部状态（选中行/滚动/过滤）。
- 实现方法：ratatui 顶层页面枚举扩展为 7 个（新增「规则」页）；沿用现有 WindowState + 每页独立状态结构；导航键位表统一在 keymap 模块。

**R1.2 全局键位与帮助**（`?` 帮助浮层、页脚常驻提示）
- 实现方法：沿用 doc/02 §2.2 键位表；帮助浮层为全屏遮罩 + 键位列表渲染。

**R1.3 语言（默认英语，rust-i18n 转中文）**
- 用户操作：设置页「语言」切换 en/zh，切换即全局生效。
- 实现方法：UI 文案默认英文；用 `rust-i18n`（i18n 宏 + en.yml/zh.yml 翻译目录）；设置项存 `clard.toml`（helper 侧），TUI 启动经 IPC 读取后初始化翻译器；翻译键集中在 `clard-tui/i18n/`。

## 2. 订阅配置（Profiles）

**R2.1 URL 导入订阅（多配置，同 URL 覆盖更新）**
- 用户操作：配置页 `i` 输入订阅 URL → 导入成功提示；名称自动派生（不提供名称输入）：优先订阅响应头 `Content-Disposition` 文件名（`filename*` → `filename`），其次 URL 最后一段路径（percent-decode），兜底「订阅」（对齐 clash-verge-rev）。同 URL 再次导入 = 覆盖更新（保留条目与名称，仅更新内容）。
- 实现方法：TUI 下载订阅（HttpFetcher：30s 超时、8MiB 上限；同时解析 `subscription-userinfo` 与 `Content-Disposition`）→ `clard-config::subscription_to_yaml` 归一化（base64 解码、节点列表转 `proxies:`）→ IPC `ProfileImport{name,url,interval,yaml}`（name 由 TUI 按上述规则派生）→ helper 校验后落盘 `/var/clard/lib/profiles/<uid>.yaml` 并原子更新索引（同 URL 覆盖、保留 uid/路径/**名称**）；**命中 current 时触发 `regenerate` 自动应用（§8.3）** → 审计 `profile.import`。下载/转换失败无副作用。

**R2.2 切换当前配置（事务）**
- 用户操作：配置页 `Enter` 切换 → 状态行「切换中…」→「已切换/失败」；核心未运行则先启动。
- 实现方法：TUI 发起 `ProfileSetCurrent`（事务）→ helper `regenerate`（§8.2：读 current 原始 yaml + settings 拼装 → 原子写 → `PUT /configs` 内联热重载 → 回读校验 → 失败回滚）→ 恢复该配置的记忆节点（`PUT /proxies/:name` 逐个，记忆存于 Profile.selected）→ 任一步失败回滚 current 并提示。更新竞态：同 uid 单在途（helper 侧 running 标记）。TUI 不再生成运行态配置。

**R2.3 手动更新订阅**
- 用户操作：配置页 `u` → 行内「更新中…」→ 成功/失败。
- 实现方法：TUI 取回该配置 URL（`ProfileGet`）→ 下载 + 归一化 → 同 URL `ProfileImport`（覆盖；**不改变名称**）→ 审计 `profile.import`。

**R2.4 删除配置**
- 用户操作：配置页 `d` → 确认 → 删除；删除当前配置后自动选中下一个并切换。
- 实现方法：IPC `ProfileRemove` → helper 删索引条目 + 内容文件，当前被删则清空 current；TUI 侧按列表顺序自动切换下一个。

**R2.5 配置改名**
- 用户操作：配置页 `r` → 输入新名称。
- 实现方法：IPC `ProfileRename{uid,name}`；helper 更新索引并落盘（导入/更新不再覆盖名称）。

**R2.6 配置排序（上移/下移）**
- 用户操作：配置页 `[`/`]` 上移/下移当前条目。
- 实现方法：TUI 调整列表顺序后经 IPC 持久化顺序（索引 items 顺序即显示顺序，helper 写回 profiles.yaml）。

**R2.7 订阅信息展示（流量/到期）**
- 用户操作：配置详情面板显示 已用/总量/到期时间。
- 实现方法：TUI 导入/更新时解析订阅响应头 `subscription-userinfo`（upload/download/total/expire），随 `ProfileImport` 一并提交；helper 存入索引扩展字段并随 `ProfileList` 返回展示。

**R2.8 自动更新（helper 全局定时，默认 6 小时，可编辑）**
- 用户操作：设置页「自动更新」输入间隔（小时，默认 6，0=关闭）；配置列表显示「下次更新」时间。
- 实现方法：间隔存 `clard.toml`（helper 侧，IPC `SettingsGet/Set` 读写）；helper 内置定时器到点串行重拉所有 remote 订阅：下载 → clard-config 转换 → 落盘覆盖（不再原样落盘）→ **命中 current 时触发 `regenerate` 自动应用（更新即生效，§8.3）** → 解析 `subscription-userinfo` 更新流量/到期 → 更新 `updated_at`（下次 = updated_at + 间隔）→ 审计 `profile.update`；失败跳过本轮记审计；与 RPC 对索引的访问经 daemon 单锁串行。手动导入（TUI 下载→转 yaml→提交）不受影响。

**R2.9 版本回滚（保留 3 份）**
- 用户操作：配置详情面板列出历史版本，`Enter` 恢复某版本。
- 实现方法：helper 在每次覆盖更新前把旧内容轮转为 `profiles/<uid>.yaml.bak.N`（最多 3 份）；`ProfileHistory` 返回版本列表，恢复 = 选定版本内容写回主文件并更新索引。

## 3. 代理（Proxies）

**R3.1 分组树与节点选择**
- 用户操作：代理页树视图，`Enter` 选中组内高亮节点。
- 实现方法：TUI 直连 `core.sock`（`GET /proxies`）渲染分组树；选择 = `PUT /proxies/:name {name:节点}`（仅 Selector 组）；mihomo 自身持久化选择。

**R3.2 清除固定选择**
- 用户操作：`d` 清除该组固定选择，回退 URLTest 自动。
- 实现方法：`DELETE /proxies/:name`（非 Selector 的 SelectAble 组）。

**R3.3 测延迟（全组）**
- 用户操作：`t`/`T` 当前选中分组测速（同一动作）；按一次 = 该分组全部节点测一次；结果显示 ms/超时，逐节点异步刷新。
- 实现方法：收集当前选中分组全部节点 → 并发逐节点 `GET /proxies/:name/delay`（参考 clash-verge `checkListDelay`，限并发 10，worker 池）→ 每节点结果经 `NodeDelay` 事件即时回写 `node_extra` 并重绘（testing → 延迟/红色 timeout）；408/503 按 delay==0 处理；节点延迟/存活初始取自 `GET /proxies` 各代理自身 `history`/`alive`。

**R3.4 测速 URL 配置**
- 用户操作：设置页「代理」输入自定义测速 URL。
- 实现方法：存 `clard.toml`；测速请求带上该 URL（缺省用 mihomo 内置）。

**R3.5 节点过滤与排序**
- 用户操作：`f` 关键字过滤；节点**固定按名称升序**显示（默认即启用，无切换快捷键）。
- 实现方法：TUI 本地对 `GET /proxies` 返回数据先过滤后按名称排序渲染（`to_ascii_lowercase`，旗标码点自然分组），不涉及后端。

## 4. 连接（Connections）

**R4.1 连接列表与实时流量**
- 用户操作：连接页表格（来源/目标/规则/延迟/收发）+ 顶部流量仪表；进入页面自动订阅流量，离开停止。
- 实现方法：`GET /connections`（WS 周期推送）渲染表格；`GET /traffic`（WS）更新仪表。

**R4.2 关闭连接（单个 / 全部）**
- 用户操作：`x` 关闭选中、`X` 关闭全部（确认）。
- 实现方法：`DELETE /connections/:id`、`DELETE /connections`。

**R4.3 排序与单位切换**
- 用户操作：`u`/`d` 按上行/下行排序；`c` 切换 KB/s ⇄ 总量。
- 实现方法：TUI 本地排序与格式化（沿用现有 format_network_bytes）。

**R4.4 连接搜索**
- 用户操作：`f` 输入关键字，按来源/目标/规则过滤。
- 实现方法：TUI 本地过滤。

**R4.5 内存占用显示**
- 用户操作：连接页/主页显示核心内存占用。
- 实现方法：`GET /memory`（WS）订阅；TUI 数值展示（TUI 文本化，不做图形）。

## 5. 规则（Rules）

**R5.1 规则列表查看**
- 用户操作：规则页（`7` 直达）列出生效规则：序号/类型/内容/策略/命中统计。
- 实现方法：`GET /rules` 渲染列表（index/type/payload/proxy/size/extra 命中统计）。

**R5.2 规则启用/禁用**
- 用户操作：`Enter` 切换单条规则启用/禁用（确认后生效）。
- 实现方法：`PATCH /rules/disable {index: bool}`（mihomo 扩展，热生效、无需重载配置）。

**R5.3 规则搜索过滤**
- 用户操作：`f` 输入关键字（按类型/内容/策略过滤）。
- 实现方法：TUI 本地过滤。

**R5.4 规则集（rule-provider）状态**
- 用户操作：规则页页签或详情列出规则集名称/行为/条目数/更新时间。
- 实现方法：`GET /providers/rules` 展示；更新规则集 = `PUT /providers/rules/:name`（可选，按钮式）。

## 6. 日志与审计

**R6.1 核心日志**
- 用户操作：日志页「核心」栏；`e` 级别过滤、`f` 关键字、`F` 跟随、`c` 清空、`G` 跳末尾。
- 实现方法：`GET /logs?level=&format=structured`（WS）订阅；环形缓冲 + 过滤渲染。

**R6.2 应用日志**
- 用户操作：日志页「应用」栏查看 TUI 自身日志。
- 实现方法：TUI `tracing` 输出经 IPC `LogSubmit` 交 helper 落盘 `/var/clard/log/tui.log`（root 0600，1MB×5 轮转）；日志页经 `LogTail` 分页读取。

**R6.3 审计日志**
- 用户操作：日志页「审计」栏：`o` 按 op 过滤、`Enter` 展开详情（actor uid/pid、cfg_sha256、net 前后快照、err）、`x` 导出、`I` 切 intent/result 配对。
- 实现方法：helper 双写 journald + `/var/clard/log/audit.log`；TUI 经 `AuditQuery` 分页读取并渲染（不读文件，防越权）。

## 7. 设置（Settings）

**R7.1 通用：混合端口 / 代理模式 / 自动更新 / 主题 / 语言**
- 用户操作：设置页「通用」：混合端口数字输入（**默认 7890，仅绑 127.0.0.1**）、**代理模式循环切换（rule 分流（默认）/ global 全代理 / direct 全直连）**、**自动更新间隔**（小时，默认 6，0=关）、主题暗/亮、语言 en/zh。
- 实现补充：托管注入 `mixed-port` 时同时把 profile 自带的 `port`/`socks-port`/`redir-port`/`tproxy-port` **归零**、`external-controller` **清空**——否则订阅自带 `port: 7890` 会先占住端口，`mixed` 监听绑定失败，`GET /configs` 回读 mixed-port=0 → R6 校验不通过（0.2.1 实测）。
- 实现方法：端口、代理模式、自动更新间隔等存 `clard.toml`（helper 侧，TUI 经 IPC `SettingsGet/Set` 读写）；**白名单字段（§8.4：mixed_port/mode/tun 系/route-exclude/exclude_*/strict/auto-redirect/log_level）变更 → 内存 patch → `regenerate`（全量拼装 + `PUT /configs` 热重载 + 回读校验）→ 成功才持久化；失败回滚，设置不静默变（§7.2）**；非白名单（language/theme/interval/test_url）仅落盘。主题/语言为纯 TUI 本地渲染状态（语言键存 clard.toml）。
- **模式语义**：`rule`=按规则分流（默认规则见 doc/01 §8.3 A，国内 GEOIP 直连 + 其余走 GLOBAL）；`global`=全流量进 GLOBAL 组（无视分流规则，即「全局代理」）；`direct`=全部直连（紧急直连/关闭代理出口）。global/direct 下默认注入的 rules 不参与选择。

**R7.2 TUN 与旁路**
- 用户操作：TUN 开关、stack（**默认 gvisor**；system/mixed 依赖防火墙放行）、**DNS 模式（fake-ip / redir-host）**、dns-hijack、route-exclude-address（默认预置私网段）；`strict-route`/`auto-redirect` 默认禁用，开启需二次确认 + 风险提示。
- **R7.2.1 DNS 页签**（设置页独立页签）：`fake-ip-filter-mode`（blacklist/whitelist/rule 循环，默认 blacklist）、`fake-ip-filter`（`*.` 通配域名列表）、`use-hosts` / `use-system-hosts`（默认 true）、`hosts`（`domain=ip` 静态映射，注入顶层 hosts）、`nameserver-policy`（`domain=dns` 按域名指定上游）、`nameserver` / `default-nameserver`（**空 = clard 默认** `[tls://223.5.5.5, tls://1.12.12.12]` / `[223.5.5.5, 119.29.29.29]`）。列表项逗号分隔编辑。**DNS 页签字段仅在 TUN 开启时生效**（dns 块 enable 由托管强制 true；TUN 关时不注入 dns 块，profile 自带 dns 原样保留；hosts 始终注入顶层）。
- 实现方法：设置项 → 存 clard.toml（`tun_dns_mode`，空/非法归一化 fake-ip）→ helper `regenerate` 时经 clard-config 注入 `tun` 托管字段（§6.3 固定值：clard0/2023/9100）+ `dns` 块（按模式：fake-ip 注入 `fake-ip-range`，两者均注入 `default-nameserver: [223.5.5.5, 119.29.29.29]` 与 `nameserver: [tls://223.5.5.5, tls://1.12.12.12]`；DoT 上游抗 UDP53 劫持，对齐 §6.3 实测结论）→ PUT /configs 热重载 → 回读校验（`GET /configs` + `ip link`/`ip rule`），未生效回退并报错（§8.2 R5–R7）。TUN 开关并入 `SettingsSet{tun_enabled}`，开启前 `precheck_tun_enable` 能力/冲突/残留检查（§8.3 D）。

**R7.3 核心：版本与升级**
- 用户操作：显示核心版本/checksum；「检查更新」「下载并升级」（确认，会短暂重启核心）。
- **自动拉起**：helper 启动时若运行态配置存在则自动启动核心（生命周期绑定 helper，服务重启/升级后核心自动恢复）；用户 StopCore 后重启 helper 仍会自动拉起（无持久化停止状态）。
- 实现方法：**安装包携带最新 mihomo（构建时下载，安装即用）**；版本取 `GET /version`（核心未运行时回退 `core.version` 文件）；checksum 取 `core.sha256` 文件（InstallCore 后写入）。升级（用户可选）= TUI Core 页 `i` **自动从 GitHub 最新 release** 下载当前架构默认变体（`.gz` 自动解压）→ 自算 sha256（官方无独立 checksum，自算哈希保证 TUI→helper 链路完整 + 记录展示）→ 写 `/run/clard/inbox/` → IPC `InstallCore{inbox_path, sha256, version}` → helper `O_NOFOLLOW` 复核哈希 → copy 非 rename 原子替换 `/var/clard/bin/mihomo` → 重启核心；哈希不符/路径越界/symlink 均拒绝并清 inbox，审计 `core.install`。`c` 检查更新对比 GitHub 最新 tag 与当前版本。

**R7.4 后台服务**
- 用户操作：helper 状态/版本/unit 状态展示；`i` 安装、`u` 卸载（先展示 dnf 命令，退出 TUI 执行后重进）。
- 实现方法：状态经 `Hello`/`Status` 获取；安装/卸载经 RPM 包管理（`sudo dnf install ./clard-*.rpm` / `sudo dnf remove clard`，安装即 `systemctl enable --now`；doc/01 §4.1/§4.4），TUI 只展示命令；构建见 `packaging/build-rpm.sh`。

**R7.5 日志与审计配置**
- 用户操作：核心日志级别、应用日志大小/份数、审计保留份数/是否双写。
- 实现方法：存 `/etc/clard/helper.toml`（root）；改动需 sudo，设置页提示命令而非直写。

**R7.6 关于**
- 用户操作：版本、协议版本、路径一览（`/run/clard`、`/var/clard/lib`、`/var/clard/cache`、`/var/clard/log`、`/etc/clard`）；「打开数据/日志目录」。
- 实现方法：`Hello` 返回版本；打开目录用系统 `xdg-open` 调起文件管理器。

## 8. 备份与恢复

**R8.1 本地备份**
- 用户操作：设置页「备份」→ 创建备份（命名/备注）→ 备份列表显示时间与大小。
- 实现方法：IPC `BackupCreate` → helper 把 `/var/clard/lib` 下 `profiles.yaml`、`profiles/`、`clard.toml` 打包为 `tar.gz` 存 `/var/clard/backups/`（运行态 runtime/ 与缓存不备份——恢复时由当前配置重新生成）；审计 `backup.create`。

**R8.2 恢复备份**
- 用户操作：备份列表 `Enter` 恢复（二次确认：将覆盖当前配置与设置）→ 恢复后自动重载配置。
- 实现方法：IPC `BackupRestore{name}` → helper 校验 tar 包结构与内容（拒绝路径穿越/超大）→ 解包到 `/var/clard/lib` → 若有 current 配置则重新生成运行态副本并热重载；审计 `backup.restore`。

**R8.3 备份管理（删除/导出）**
- 用户操作：备份列表删除；导出到用户指定目录（如 `~/Downloads`）。
- 实现方法：`BackupDelete`（helper 删文件）；导出 = TUI 经 IPC 读取备份字节写入用户目录（TUI 本地落盘，不属于系统数据）。

## 9. 明确不做（决策 + TUI 可行性）

| 功能 | 原因 |
|---|---|
| local 配置 / YAML 编辑器 | 决策（一期仅 URL 导入） |
| script 增强 / merge / rules-proxies-groups 追加 | 决策（订阅外扩展不做） |
| Chain 代理链 | 决策 |
| 启动页可配置 | 决策（TUI 默认主页） |
| 开机自启开关 | 决策（helper 为 systemd 常驻服务，天然自启） |
| 系统代理 / PAC / 绕过列表 | clard 数据面 TUN-only（01 附录 A） |
| 多内核切换（mihomo 系多版本） | 决策（单一核心 + 版本升级） |
| Web UI / 内置面板 | TUI 直连 API 即可，无界面托管需求 |
| 托盘 / 通知 / 全局热键 / 静默启动 | 终端无托盘/通知概念 |
| 流量图 / 分组图标 / 延迟历史曲线 | 图形化渲染，TUI 用数值/列表替代 |
| 媒体解锁检测 | 探测目标（Netflix/Disney…）需长期维护、易失效，TUI 成本高 |
| DNS 配置编辑器 | 与托管 fake-ip 冲突，DNS 细节交由配置模板 |
| WebDAV 备份 | 协议与凭据管理复杂，只做本地备份恢复 |
| UWP 回环 / 轻量模式 | Windows/GUI 专用 |
| 节点详情展开（链/直连详情） | TUI 表格空间有限，列表已含规则列 |
