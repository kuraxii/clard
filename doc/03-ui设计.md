# Clard 完整代理管理工具 — UI/UX 设计

> 版本：v0.2（设计稿） · 目标平台：Linux · 界面：TUI（ratatui） · 状态：待评审
> 与 `01-方案设计.md`（TUN-only + `clard-helper` 常驻）配套；需求基线见 `05-需求文档.md`。
>
> TUI 交互简单，交互（UX）与界面（UI）合并于本文档。数据面只有 TUN（+ 可选的手动混合端口）。
> **前提**：后台服务 `clard-helper`（root，systemd 单元）是**系统级服务、不分用户**，拥有核心、TUN 与全部数据（/var）；TUI 只是客户端，**退出/崩溃/多开都不影响后台代理**，全程不需要 su。

## 1. 设计原则

1. **键盘优先**：所有高频操作必须有单键/组合键直达，无鼠标依赖。
2. **即时反馈**：任何命令（切换、更新、测试）立即给出「进行中 → 成功/失败」，不静默。
3. **不丢状态**：切换页面不重置列表滚动位置与选中项；错误只提示不阻塞。
4. **危险操作需确认**：删除配置、关闭全部连接、卸载服务、恢复备份等破坏性动作二次确认。
5. **可发现性**：页脚常驻快捷键提示；`?` 打开全局帮助。
6. **语言**：默认英语（en），`rust-i18n` 中文（zh）翻译，设置页切换。

## 2. 全局框架

每个页面共用四段式骨架，内容区按页面替换：

```
┌────────────────────────────────────────────────────────────────────────┐
│ ① 顶栏 Header（3 行）                                                  │
│    Clard · helper: Connected · core: Running · TUN: On · profile: A    │
├────────────────────────────────────────────────────────────────────────┤
│ ② 导航 Nav（1 行）                                                     │
│    [1 Home] [2 Profiles] [3 Proxies] [4 Conn] [5 Logs] [6 Settings]    │
│    [7 Rules]                                                           │
├────────────────────────────────────────────────────────────────────────┤
│  ③ 内容 Content（可滚动，Min 高度）                                    │
│      · 列表 / 树 / 表格 / 表单 / 日志                                  │
├────────────────────────────────────────────────────────────────────────┤
│ ④ 页脚 Footer（2 行）                                                  │
│    帮助键提示行：↑↓ Move · Enter OK · q Quit · ? Help                  │
│    消息条：最近一条 成功/警告/错误                                     │
└────────────────────────────────────────────────────────────────────────┘
```

- 终端 **最小尺寸**：80×24；小于该值显示居中提示「Please enlarge terminal / 请放大终端」，不渲染内容。
- 内容区用 `Constraint::Min(0)` 自适应；列表超出可滚动，右侧显示滚动条。

## 3. 配色主题

暗色为默认（亮色为反相变体），语义色全站一致：

| 角色 | 颜色（256 色） | 用途 |
|---|---|---|
| 背景 | `#1e1e2e` / 亮色 `#f5f5f5` | 全屏底 |
| 面板 | `#2a2a3a` / `#ffffff` | 卡片、列表底色 |
| 边框 | `#45475a` | 区块边框 |
| 主文字 | `#cdd6f4` / `#333` | 正文 |
| 次级文字 | `#6c7086` | 说明、提示 |
| 强调色 | `#89b4fa`（蓝） | 选中、焦点、当前项 |
| 成功 | `#a6e3a1`（绿） | Running、开、成功 |
| 警告 | `#f9e2af`（黄） | 更新中、降级 |
| 错误 | `#f38ba8`（红） | 失败、致命 |
| 高亮强调 | `#cba6f7`（紫） | 数字、延迟值、速率 |

- 选中项：强调色文字 + 深一档背景（`#313244`）。

## 4. 全局导航与键位

### 4.1 页面（状态机）

```
┌─────────┐  1  ┌───────────┐  2  ┌──────────┐  3  ┌─────────────┐
│ 主页     │────▶│ 配置文件   │────▶│ 代理      │────▶│ 连接         │
│ Home    │     │ Profiles  │     │ Proxies  │     │ Connections │
└─────────┘     └───────────┘     └──────────┘     └─────────────┘
     ▲                                                    │
     │        6  ┌──────────┐  5  ┌──────────┐            │
     └───────────│ 设置      │◀────│ 日志      │◀───────────┘
                 │ Settings  │     │ Logs      │
                 └──────────┘     └──────────┘
     ┌──────────┐  7
     │ 规则      │
     │ Rules    │
     └──────────┘
```

- 页面用 `1`–`7` 数字直达；`Tab` 进入内容区、`Esc` 返回/退出（见各页）。
- 页面间切换**保留**各自内部状态（选中行、滚动、过滤条件）。

### 4.2 全局键位（默认）

| 键 | 作用 | 备注 |
|---|---|---|
| `1`–`7` | 直达对应页面 | 主页/配置/代理/连接/日志/设置/规则 |
| `↑` `↓` / `j` `k` | 列表上下移动 | 全页通用 |
| `←` `→` / `h` `l` | 左右面板切换 / 树展开收起 | 分栏页 |
| `Enter` | 确认 / 进入 / 触发主操作 | |
| `Tab` | 聚焦下一区域 / 切换页签 | |
| `Esc` | 返回上一层 / 关闭弹窗；主页时为退出 | |
| `q` | 退出（主页/弹窗外任意处） | 有未完成任务时确认 |
| `?` | 全局帮助浮层 | 任意页 |
| `Ctrl+c` | 强制退出（兜底） | 退出不影响后台核心与 TUN；停代理用 `S`（停核心）或 `D`（紧急恢复直连） |

### 4.3 弹窗与确认

- **确认弹窗**：`Enter`=确认，`Esc`=取消，默认焦点在「取消」。
- **输入弹窗**（订阅 URL、搜索、数字输入）：单行输入，`Ctrl+u` 清行、`Backspace` 删字符、`Enter` 提交、`Esc` 取消。
- **帮助浮层**：全屏半透明遮罩 + 键位表，`?`/`Esc` 关闭。

## 5. 页面 UI 与交互

### 5.1 主页（Home / `1`）

**用途**：一屏总览，不承载复杂操作。

```
┌─ Core ───────────────────────────┐
│  State: ● Running    PID: 1234   │
│  mihomo 1.19.2       restarts: 0 │
│  Mixed port: 7890 (127.0.0.1)    │
└──────────────────────────────────┘
┌─ TUN ─────────────┐ ┌─ Profile ────────────┐
│  ● On · clard0    │ │  Name: 订阅A (remote) │
│  tbl 2023 · r9100 │ │  updated: 2h ago     │
│  verified: ✓      │ │  next update: 22h    │
└───────────────────┘ └──────────────────────┘
┌─ Traffic ──────────────────────────┐
│  ↑ 12.3 KB/s  ↓ 456.7 KB/s        │
│  total ↑1.2GB ↓34.5GB  exit: 节点A │
└────────────────────────────────────┘
```

| 区域 | 展示 | 交互 |
|---|---|---|
| 后台服务 | helper 连接状态（Connected / unreachable / not installed）+ 版本 | `Enter` 详情；未安装时 `i` 安装（RPM，`sudo dnf install ./clard-*.rpm`，仅一次） |
| 核心状态 | Running/Starting/Stopped/**Degraded** + PID + 重启次数 + 版本 | `s` 启动/重启，`S` 停止（确认） |
| TUN | 开/关 + 生效校验（clard0 / 2023 / 9100）+ 不可用原因 | `t` 切换（确认后热重载），`D` 紧急恢复直连（确认） |
| 当前配置 | 名称、类型、上次/下次更新 | `Enter` 跳到 Profiles 页 |
| 流量摘要 | 上/下行速率与总量、当前出口线路 | 只读 |

- TUN 卡能力不足时灰色 `○ Off` + 红色 reason（如「no /dev/net/tun」），提示手动模式退路（应用自填 `127.0.0.1:7890`）。
- Degraded 时核心状态卡红框 + 「已 fail-open 恢复直连，`s` retry」。

### 5.2 配置文件（Profiles / `2`）

**用途**：订阅配置全生命周期管理。

```
┌ Profiles (3) ──────────────┐ ┌ Detail ─────────────────────┐
│  ▸ ● 订阅A      更新中…    │ │ Name: 订阅A                 │
│     订阅B       ✓ just now │ │ Type: remote               │
│     订阅C       ✗ failed   │ │ URL:  https://…/sub        │
│                            │ │ Traffic: 5G / 100G         │
│  [i import] [u update]     │ │ Expire: 2026-01-01         │
│  [r rename] [d delete]     │ │ updated: 2h ago · next: 22h │
└────────────────────────────┘ └────────────────────────────┘
```

| 键 | 动作 | 反馈 |
|---|---|---|
| `↑↓/jk` | 移动选中 | 高亮行 |
| `Enter` | 切换为当前配置 | 状态行「switching…」→「switched/failed」 |
| `i` | 从 URL 导入（可选名称） | 行内「importing…」spinner |
| `u` | 立即更新选中订阅 | 行内「updating…」 |
| `[` / `]` | 上移 / 下移排序 | 即时重排 |
| `r` | 重命名 | 输入弹窗 |
| `d` | 删除 | 确认弹窗 |
| `v` | 查看内容 | 只读分页视图 |
| `h` | 版本历史（回滚） | 历史列表，`Enter` 恢复 |

- 行前缀：`●` 当前配置；`✓` 最近更新成功；`✗` 上次失败；spinner 更新中。
- 详情面板：uid、类型、URL、**流量/到期**（subscription-userinfo）、上次/下次更新。
- `Enter` 切换时若核心未运行，先启动核心再切换；删除「当前」配置时自动选中下一个并切换。

### 5.3 代理（Proxies / `3`）

**用途**：分组树、节点选择、测延迟。

```
┌ Groups ───────────────────┐ ┌ Nodes (Proxy) ─────────────┐
│  ▾ ● Proxy     [auto] 132 │ │  ▸ 节点A          132 ms   │
│    ▸ 节点A · 节点B · 节点C │ │    节点B           88 ms   │
│  ▸ Netflix     [auto] 210 │ │    节点C         timeout   │
│  ▾ Fallback    [manual] A │ │  [t/T test all]             │
└───────────────────────────┘ └────────────────────────────┘
```

| 键 | 动作 |
|---|---|
| `↑↓/jk` | 上下移动 |
| `←→/hl` | 折叠/展开分组，或左右栏切换 |
| `Enter` | 选中组内高亮节点（`PUT /proxies/:name`） |
| `t`/`T` | 当前选中分组测速（逐节点并发，异步实时刷新延迟） |
| `d` | 清除该组固定选择（回退 URLTest 自动） |
| `f` | 过滤（输入关键字） |

- `▸/▾` 折叠态；`●` 当前分组；`[auto]/[manual]` 选择来源；右侧延迟值。
- 节点固定按名称升序显示（旗标码点自然分组，如香港在前）；延迟颜色：<180ms 绿、<500ms 黄、超时（delay=0）红 `timeout`。

### 5.4 连接（Connections / `4`）

**用途**：活跃连接与实时流量。

```
┌ Traffic: ↑ 12.3KB/s ↓ 456.7KB/s · conns 48 ──────────────┐
├ Source                 Dest               Rule     Delay  UL/DL ┤
│ ▸ 192.168.1.5:52000 →  104.16.x.x:443    Proxy  132ms ↑2.1↓8.3│
│   192.168.1.5:52001 →  8.8.8.8:53        DIRECT 1ms  ↑0.1↓0.1│
└────────────────────────────────────────────────────────────┘
  sort:u/d · close:x · all:X · unit:c · refresh:r · filter:f
```

| 键 | 动作 |
|---|---|
| `↑↓/jk` | 移动选中连接 |
| `u` / `d` | 按上行 / 下行排序 |
| `x` | 关闭选中连接 |
| `X` | 关闭全部连接（确认） |
| `c` | 切换流量单位（KB/s ⇄ 总量） |
| `f` | 关键字过滤（来源/目标/规则） |
| `r` | 手动刷新 |

- 进入本页自动订阅 `traffic`/`connections` WebSocket，离开停止。
- 规则列着色：`DIRECT` 灰、`Proxy` 蓝、`REJECT` 红。

### 5.5 规则（Rules / `7`）

**用途**：查看生效规则、启用/禁用、搜索。

```
┌ Rules (42) ─────────────────────────────────────────────┐
│ #   Type    Payload          Proxy    Hits  State        │
│ ▸ 0  DOMAIN  google.com      节点A   1234  enabled       │
│   1  GEOIP   CN              DIRECT  998   enabled       │
│   2  MATCH   *               节点A     -    disabled     │
└─────────────────────────────────────────────────────────┘
  toggle:Enter · filter:f · providers:Tab
```

| 键 | 动作 |
|---|---|
| `↑↓/jk` | 移动选中 |
| `Enter` | 启用/禁用当前规则（`PATCH /rules/disable`，热生效） |
| `f` | 关键字过滤（类型/内容/策略） |
| `Tab` | 切换到「规则集（rule-providers）」视图 |
| `u` | 更新选中规则集（可选） |

- 列：序号/类型/内容/策略/命中统计/状态；`disabled` 行灰色。
- 数据源 `GET /rules`；规则集视图 `GET /providers/rules`。

### 5.6 日志（Logs / `5`）

**用途**：应用 / 核心 / **审计** 三类日志查看与诊断。

```
┌ [App] [Core] [Audit] [Merged]  level:info · follow:● ────┐
│ 09:12:01 [Info ] [Core  ] core started pid=1234          │
│ 09:12:03 [Warn ] [Timer ] profile B update failed:timeout│
│ 09:12:04 [Info ] [Audit ] tun.enable uid=1000 → ok       │
│ 09:12:09 [Error] [Audit ] config.apply → reject          │
└──────────────────────────────────────────────────────────┘
  level:e · filter:f · follow:F · clear:c · end:G
  audit: op:o · detail:Enter · intent/result:I · export:x
```

| 键 | 动作 |
|---|---|
| `Tab` | 循环切换 应用 / 核心 / 审计 / 合并 |
| `↑↓/jk` | 滚动（跟随尾部时先解除） |
| `e` | 级别过滤（error→warn→info→debug） |
| `f` | 关键字过滤 |
| `F` | 跟随/取消跟随尾部 |
| `c` | 清空当前视图 |
| `G` | 跳到末尾 |

- 行格式 `HH:MM:SS [level] [source] msg`，级别四色。
- **审计栏**：`o` 按 op 过滤（`tun.enable`/`config.apply`/`core.crash`/`watchdog.failopen`/`cleanup.tun`/`policy.reject`/`profile.import`/`backup.*`/`rpc.error` …）；`Enter` 展开（actor uid/pid、auth 方式、`cfg_sha256` 与字段级 diff、net 前后快照、err）；`x` 导出到用户指定目录；`I` 切 intent/result 配对。
- 审计内容**不包含**订阅凭据与节点密码（只显示字段名与哈希）。

### 5.7 设置（Settings / `6`）

左侧设置项 + 右侧值（或页签式，按实现取舍）：

```text
┌ [General] [DNS] [TUN] [Core] [Service] [Backup] [Logs] [About] ┐
│  fake-ip-filter-mode: [blacklist]           ↻            │
│  fake-ip-filter:      *.lan,*.local         ↻            │
│  use-hosts:           ● on                  ↻            │
│  use-system-hosts:    ○ off                 ↻            │
│  hosts:               oa.x=10.0.0.1         ↻            │
│  nameserver-policy:   +.corp=10.10.0.2      ↻            │
│  nameserver:          default (tls://…)     ↻            │
│  default-nameserver:  default (223.5.5.5,…) ↻            │
│  ↑↓ select · Enter edit · ↻=hot reload · !=confirm      │
└──────────────────────────────────────────────────────────┘
```

| 页签 | 配置项 | 交互 |
|---|---|---|
| General | 混合端口（**默认 7890，仅 127.0.0.1**）、**代理模式（rule 分流 / global 全代理 / direct 全直连，循环切换）**、**自动更新间隔（小时，默认 6，0=关）**、语言（en/zh）、主题（暗/亮）、允许局域网（默认关） | 数字/枚举输入；`↻` 热重载 |
| DNS | **fake-ip-filter-mode（blacklist/whitelist/rule 循环）**、fake-ip-filter（`*.` 通配）、use-hosts / use-system-hosts、hosts（`domain=ip` 静态映射，顶层注入）、nameserver-policy（`domain=dns` 按域名指定上游）、nameserver / default-nameserver（**空 = clard 默认**）；**仅 TUN 开启时生效**（enable 托管强制） | 布尔/枚举循环切换；列表项逗号分隔多行编辑；改动热重载（`↻`）+ 读回校验 |
| TUN | TUN 开关、stack、dns-hijack、route-exclude（默认私网段）；`strict-route`/`auto-redirect`（**默认禁用**，开启需二次确认 + 风险提示） | 开关后热重载 + **读回校验**（`GET /configs` + `ip link`/`ip rule`），未生效回退并报错 |
| Core | 版本/checksum、检查更新、下载并升级 | 升级需确认（短暂重启核心） |
| Service | helper 状态/版本、unit 状态 | `i` 安装、`u` 卸载——先展示 `dnf` 命令，退出 TUI 执行后重进 |
| Backup | 备份列表（时间/大小）、创建、恢复、删除、导出 | 创建可命名；恢复二次确认（覆盖当前配置与设置） |
| Logs | 核心日志级别、应用日志大小/份数、审计保留份数/双写 | 改动写 `helper.toml` → 提示 sudo 命令 |
| About | 版本、协议版本、路径一览（`/run/clard`、`/var/clard/lib`、`/var/clard/cache`、`/var/clard/log`、`/etc/clard`）、打开数据/日志目录 | 只读；打开目录用 `xdg-open` |

- 布尔项 `●/○`；枚举项 `[值]` 循环切换；数字项弹出输入框；列表项进多行编辑弹窗。
- **`↻` = 经 IPC 热重载生效**（`PUT /configs` 内联 payload），常规项无需重启核心；只有核心升级会重启。
- **`!` = 危险项**（`strict-route`、`auto-redirect`、局域网共享、卸载服务、恢复备份）：二次确认 + 风险文案（引用 `01-方案设计.md` §6.3/§6.4）。
- 设置改动经 IPC 由 helper 写盘（`/var/clard/lib/clard.toml`）；被 helper 策略校验拒绝时，消息条给出原因并在审计留 `policy.reject`。

## 6. 状态与错误反馈

三种通道，避免信息丢失：

1. **页脚消息条**：最近一条结果（成功/失败 + 原因），5 秒后淡出，`m` 查看历史。
2. **行内状态**：列表项实时状态（更新中 spinner、延迟值、错误标记）。
3. **日志页**：可诊断细节沉淀到日志，消息条只给结论。

错误分级：

| 级别 | 展示 | 例 |
|---|---|---|
| info | 页脚灰字 | 「profile switched」 |
| warn | 页脚黄字 | 「profile update failed, old kept」 |
| error | 页脚红字 + 日志 | 「core start failed: port in use」 |
| fatal | 弹窗 + 停止操作 | 「profile invalid, cannot generate config」、「helper unreachable（`systemctl status clard-helper`）」、「core crashed repeatedly, fail-open」 |

## 7. 典型任务流

### 7.1 首次使用（导入并启动）

```
启动 → Home 提示「service not installed」→ 6 Settings → Service → i install
     （RPM 安装一次；安装期间退出 TUI，完成后重进）
     → helper Connected → 2 Profiles → i 输入订阅 URL → Enter 导入
     → Enter 切换 → helper 自动启动核心 → Home Running + profile
     → 6 Settings → TUN → TUN on → 热重载 + 读回校验通过
     → Home 确认「TUN: On · clard0 · tbl 2023」→ 完成
     → 关掉 TUI：代理照常工作（helper 常驻，systemd 监督）
```

### 7.2 TUN 开不起来（能力不足）

```
6 Settings → TUN → on → 能力探测失败
  → 结构化 reason：no /dev/net/tun · no CAP_NET_ADMIN · clard0/tbl2023/r9100 被占用 · 缺 iproute2 · core 未安装
  → TUN 保持 off，设置不被静默修改；提示手动模式退路（127.0.0.1:7890）
```

### 7.3 排查断网

```
Home D 紧急恢复直连（cleanup-tun：删 rule 9100..9110 → flush tbl 2023 → 删 clard0 → 校验）
5 Logs → Audit → o 过滤 op=tun.enable / watchdog.failopen / cleanup.tun / core.crash
     → Enter 展开 actor/diff/net 快照/err → Core 栏 e error 定位根因
Home Degraded → s retry 或 S stop
```

### 7.4 后台服务不可达

```
启动 → 连接 helper.sock 失败 → 全屏提示「service unreachable: not installed or not running」
     → 提供 i 安装（RPM）/ 帮助 / 退出
```

### 7.5 恢复备份

```
6 Settings → Backup → 选中备份 → Enter 恢复（二次确认：覆盖当前配置与设置）
     → helper 校验并解包 → 自动重载配置 → 消息条「backup restored」
```

## 8. 通用组件规格

| 组件 | 规格 |
|---|---|
| 列表 | 行高 1，选中反色，右侧滚动条，空态居中「(empty)」 |
| 表格 | 表头粗体+分隔线，列宽固定，单元格溢出截断加 `…` |
| 弹窗 | 居中，宽 ≤ 内容+4，遮罩半透明，标题栏 + 内容 + 按钮行 |
| 输入框 | 单行，光标闪烁，`Ctrl+u` 清行 |
| spinner | `⠋⠙⠹⠸⠼⠴⠦⠧⠇⠏` 每秒 10 帧，用于「更新中/切换中/测试中」 |
| 消息条 | 右对齐，成功绿/警告黄/错误红，5 秒淡出 |

## 9. 尺寸与响应式

| 宽度 | 行为 |
|---|---|
| < 80 列 | 显示「Please enlarge terminal」，不渲染 |
| 80–110 列 | 分栏页压缩详情栏宽度，列表优先 |
| > 110 列 | 全部分栏展开 |

高度不足 24 行同样提示；内容区在两者之间自适应收缩。

## 10. 无障碍与可配置

- 键位集中定义在 `clard-tui` 的 `keymap` 模块，后续支持自定义键位文件。
- 颜色集中于 `theme` 模块，暗/亮一键切换；后续可读 `clard.toml` 的 `[theme]` 段自定义。
- 文案默认英语（`rust-i18n`），`zh.yml` 提供中文翻译；语言键存 `clard.toml`（helper 侧）。
