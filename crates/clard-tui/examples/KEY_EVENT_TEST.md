# 真实按键事件测试

## 说明

这个测试程序用于观察连续按键时的真实事件行为，帮助优化 TUI 中的按键处理逻辑。

## 运行方法

```bash
cargo run --example key_event_test
```

## 测试步骤

1. 运行测试程序
2. 连续按下方向键（上/下/左/右）
3. 观察控制台输出的事件时序
4. 按 Ctrl+C 退出测试

## 输出说明

### 事件类型

- `[Press]`：按键按下事件
- `[Release]`：按键释放事件
- `[Repeat]`：按键重复事件（如果系统支持）
- `[Other]`：其他按键事件类型

### 输出格式

```
[序号] [事件类型] 按键码 at 时间戳ms
         -> 分析结果
```

### 分析结果

- `短按 (< 100ms)`：适合单次导航
- `中等按 (100-500ms)`：介于短按和长按之间
- `长按 (> 500ms)`：需要实现连续滚动

### 统计信息

测试结束时显示：
- 总事件数
- 测试时长
- 平均事件率

### 分析建议

1. **观察按键重复间隔**：
   - 如果间隔 < 50ms，系统按键重复率高
   - 如果间隔 > 100ms，系统按键重复率低

2. **观察按键持续时间**：
   - 短按 (< 100ms)：适合单次导航
   - 长按 (> 500ms)：需要实现连续滚动

3. **观察事件类型**：
   - 如果有 Repeat 事件：可以直接利用
   - 如果只有 Press/Release：需要自己实现连续滚动

## 优化方向

根据测试结果，可以：

1. **实现连续滚动定时器**：
   - 首次按键立即响应
   - 检测到长按后启动定时器
   - 按固定间隔（如 50ms）持续滚动

2. **实现按键状态跟踪**：
   - 维护当前按住的按键集合
   - 支持多键组合（如 Shift + 方向键加速）

3. **优化渲染性能**：
   - 限制渲染频率
   - 使用脏标记避免不必要的重绘

## 注意事项

1. **系统差异**：不同操作系统的按键重复率可能不同
2. **终端差异**：不同终端可能对按键事件的处理方式不同
3. **环境差异**：SSH 连接可能影响按键事件的时序
